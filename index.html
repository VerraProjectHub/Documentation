info Platform Overview

The Verra Project Hub (the project hub) is an online platform that serves as a comprehensive tool for listing, registering, and managing projects in Verra's standards programs.

The project hub enables the submission and review of documentation for project validation, registration, monitoring, verification, and related processes. Project proponents can use it to track the progress of project review processes, milestones, and deliverables, and to complete a number of actions related to these processes.

How the Project Hub Supports Stakeholders

  • Enhances transparency and accessibility of project information.
  • Facilitates communication and collaboration among proponents, validation/verification bodies (VVBs), and other stakeholders.
  • Streamlines the processes necessary to complete registration, validation, and verification of projects.

play_arrow Getting Started

Begin your journey with the Verra Project Hub by following these essential steps. Whether you're a new project developer or an experienced validator, this guide will help you navigate the platform effectively.

1. Account Setup & Access

Create your Verra account and configure your profile with the necessary credentials and organizational information. Ensure you have the appropriate permissions for your role in the carbon market ecosystem.

2. Project Registration

Learn how to register new projects, select appropriate methodologies, and submit initial documentation. The platform guides you through each step of the registration process with built-in validation checks.

3. Document Management

Master the document submission system, track review statuses, and respond to validator feedback efficiently. The system supports various document types and provides automated notifications for status changes.
